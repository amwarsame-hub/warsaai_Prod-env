Start from a design system that already works

Every build in this pipeline begins from a DESIGN.md pulled from a real, shipped product — in this case Stripe's — instead of guessing at "nice." Tokens, type scale, and component shapes are fixed before a single page gets written.

Taste, not averages

Deliberate rhythm and asymmetry keep the layout from reading as flat, generated sameness.

Polished on purpose

A critique pass checks hierarchy, spacing, and contrast before anything ships.
